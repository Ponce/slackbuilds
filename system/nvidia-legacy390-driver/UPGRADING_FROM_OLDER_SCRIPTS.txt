UPGRADING FROM OLDER SCRIPTS

The script has been cleaned up and changed, as well as nvidia-switch.
The files doinst.sh and douninst.sh no longer automatically create
/etc/X11/xorg.conf, so you will have to do that yourself.

After removing the driver with 'nvidia-switch --remove' and removepkg,
You MUST do these before running the new script

If /usr/lib$LIBDIRSUFFIX/xorg/modules/libwfb.so is a symlink, first
remove it and reinstall xorg-server (pkgtools seems to not overwrite
symlinks).  Then you can run the .SlackBuild script and install it as
 normal.
